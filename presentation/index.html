Documentation Agent

An AI agent on Amazon Bedrock AgentCore that keeps a repository's documentation from falling behind — automatically.

Docstrings · README · Drift detection · Triggered on every push

The problem

Documentation rots fast

  • README files go stale
  • Functions ship with no docstrings
  • Docs drift out of sync with the code

Nobody has time to fix it by hand — so it never gets fixed.

The solution

An agent that documents for you

Docstrings

Finds functions/classes/modules missing docstrings (via ast) and writes them with Claude on Bedrock.

README

Generates & refreshes a project README from every module's purpose + public API.

Drift detection

Flags docstrings inconsistent with the code (renamed params, wrong Returns).

Human-in-the-loop

Never writes to main — it opens a Pull Request for review.

How it works — end to end

Event-driven, chunked, serverless

One file per chunk → parallel & conflict-free. The whole project is documented per push.

Inside the agent

Hexagonal agent, pluggable tools

Domain logic (ast analyzer, renderer, drift, README) sits behind ports; adapters (Bedrock, GitHub REST) are swappable — every capability is a Strands @tool.
