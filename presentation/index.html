Documentation Agent

An AI agent on Amazon Bedrock AgentCore that keeps a repository's documentation from falling behind — automatically.

Docstrings · README · Drift detection · Triggered on every push

The problem

Documentation rots fast

  • README files go stale
  • Functions ship with no docstrings
  • Docs drift out of sync with the code

Nobody has time to fix it by hand — so it never gets fixed.

The solution

An agent that documents for you

Docstrings

Finds functions/classes/modules missing docstrings (via ast) and writes them with Claude on Bedrock.

README

Generates & updates a project README from every module's purpose + public API.

Drift detection

Flags docstrings that no longer match the code (e.g. renamed parameters).

Human-in-the-loop

Never writes to main — it opens a Pull Request for review.

How it works

Event-driven, chunked, on AWS

GitHub push → API Gateway → Webhook Lambda (verify HMAC)
  → Orchestrator Lambda (enumerate files, fan out)
    → Chunk Lambda × N  (one file each, in parallel)
      → Claude on Bedrock → commit → 1 Pull Request

Bedrock AgentCore Runtime Claude (Bedrock Converse) Lambda fan-out GitHub REST API

One file per request = fast, parallel, conflict-free. The whole project gets documented per push.
