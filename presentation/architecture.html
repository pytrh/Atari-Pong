Documentation Agent
— Architecture

Event-driven, chunked, serverless — on Amazon Bedrock AgentCore.

Trigger → fan-out → pull request

End-to-end architecture

One file per chunk → parallel, conflict-free. The whole project is documented per push.

Inside the agent

Hexagonal agent, pluggable tools

Domain logic (ast analyzer, renderer, drift, README) sits behind ports; adapters (Bedrock, GitHub REST) are swappable — every capability is a Strands @tool.

What it does

Four capabilities, one pipeline

  • Docstrings — detect (via ast) & generate for modules, classes, functions
  • README — generate/refresh a project README from every module
  • Drift detection — flag docstrings inconsistent with the code (renamed params, wrong Returns)
  • Delivery — never touches main; opens a Pull Request for review
